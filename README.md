# ☕ Java Beginner Projects

A collection of beginner-friendly Java projects designed to strengthen my understanding of **Core Java** through hands-on, practical coding.

This repository is about moving beyond syntax tutorials and actually *building* applications—understanding how Java works by using it to solve real problems.

## 🎯 Objective

Build a strong Java foundation by progressively mastering:

- Variables, data types, and operators
- User input with `Scanner`
- Control flow (conditionals, loops)
- Methods and functions
- Arrays and Strings
- Problem-solving and debugging

**No frameworks. No libraries. Just Core Java.** ☕

---

## 🚀 How to Use This Repository

1. **Follow the progression**: Projects are designed to build on each other—start with Project 01
2. **Code along**: Clone the repo, run each project, and modify the code
3. **Experiment**: Try edge cases, break things, debug, and learn from mistakes

## 📋 Project Details

### 01 — Can I Afford It?

Determines if a user can afford an item based on income, expenses, and item price.

**Concepts:** Variables, data types, Scanner, arithmetic, if/else

---

### 02 — Student Grade Calculator

Converts student marks into letter grades using conditional logic.

**Concepts:** User input, conditionals, comparison operators

---

### 03 — Savings Goal Calculator

Calculates how long it takes to reach a savings target based on monthly contributions.

**Concepts:** Methods, arithmetic, variable manipulation

---

### 04 — Budget Calculator

Tracks income and expenses to calculate remaining balance.

**Concepts:** Methods, Scanner, arithmetic, conditionals

---

### 05 — Number Guessing Game

Interactive game where the player guesses a random computer-generated number.

**Concepts:** Random, loops, conditionals, user input, game mechanics
